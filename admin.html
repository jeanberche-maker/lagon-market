Publier sur l'app

1. Téléchargez le fichier · 2. Déposez-le sur GitHub · 3. Les clients sont à jour au prochain cycle (≤ 5 min).

📖 Déposer le fichier sur GitHub (pas à pas)
  1. Ouvrez github.com → Add file → Upload files (compte jeanberche-maker).
  2. Glissez le fichier products.json téléchargé.
  3. Cliquez Commit changes — la publication en ligne est automatique (~1 min).

Vos changements en attente restent enregistrés sur ce téléphone (bouton « Voir le brouillon » ci-dessous si besoin).
